BINDHYA MULTISPECIALITY HOSPITAL — STATIC WEBSITE

Files:
- index.html: complete responsive website (HTML and CSS included)
- assets/: supplied hospital posters/images

Preview:
Open index.html in a browser.

Publish:
Upload index.html and the complete assets folder to your web host's public_html/root directory. Keep the assets folder beside index.html.

Before publishing:
1. Confirm spelling/transliteration of doctor names and credentials with the hospital.
2. Confirm the address, phone numbers, services, and social media URL.
3. Add the hospital's official logo as a separate image if a clean logo file is available. The current header uses the supplied poster image as a temporary emblem image.
4. Add a privacy policy and any required business/contact details appropriate for the hospital.
5. A website alone does not guarantee Meta/WhatsApp Business approval; make sure all business details are accurate and consistent with the Meta Business account.
